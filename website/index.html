The problem

AI context files multiply and drift

Claude Code reads CLAUDE.md. OpenCode reads AGENTS.md. Cursor reads .cursorrules. Across ten repos these files diverge. Cascade keeps one source and writes the others automatically.

🌏

Six-tier hierarchy

Rules flow from global to app-level. Lower tiers add specificity. Higher tiers set defaults. Conflicts resolve predictably.

⚙

Auto-generate harness files

One CASCADE.md per scope. Cascade writes CLAUDE.md, AGENTS.md, .cursorrules, and more whenever your files change.

🔍

Local RAG search

FTS5 keyword search + Multilingual E5 Large dense embeddings + RRF fusion. Query your entire instruction corpus in milliseconds. No cloud.

🔌

MCP server

Live context injection into any MCP-compatible tool. Your cascade becomes a queryable context source, not just static files.

🛠

WASM plugins

Ingest GitHub Issues, Jira, Linear, and more into your RAG index. Plugins run sandboxed in wasmtime with declared permissions.

🔒

Local-first

No cloud sync. No account required. Your instructions live in plain Markdown files on disk, under your control.

The six tiers

One hierarchy, all your scopes

Every working directory resolves a complete instruction set by walking up through six tiers. Each tier inherits from the one above and can override or extend it.

Tier Name Default location
GCI Global Cascade Instructions ~/.cascade/CASCADE.md
PCI Personal Cascade Instructions ~/Downloads/.cascade/CASCADE.md
APC All-Projects Cascade ~/Sites/.cascade/CASCADE.md
PPC Per-Project Cascade ~/Sites/myproject/.cascade/CASCADE.md
PRC Per-Repo Cascade ~/Sites/myproject/myrepo/.cascade/CASCADE.md
PAC Per-App Cascade myrepo/apps/myapp/.cascade/CASCADE.md
How it works

From init to consistent context

Three commands are all you need to get started. After that, the daemon handles everything automatically.

1

Initialize

Run cascade init in your project. Cascade creates a .cascade/CASCADE.md skeleton and registers the project with the background daemon.

2

Write your rules

Edit CASCADE.md in plain Markdown. Rules at this level apply to this repo. Global rules go in ~/.cascade/CASCADE.md.

3

Generate harness files

Run cascade generate-instructions. Cascade merges all tiers and writes CLAUDE.md, AGENTS.md, and any other configured tool files.

4

Stay in sync automatically

The daemon watches your CASCADE.md files. Any edit triggers a re-merge and re-generation. Your tools always see current context.
